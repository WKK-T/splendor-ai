# v1.0.0 发布验证

2026-10-26 在 Mac Apple Silicon 上对整理后的公开版本进行了验证。

| 验证对象 | 结果 |
| --- | --- |
| Rust 基础规则 | 固定 Rust 1.85.1，30 项测试通过 |
| 浏览器玩法 | 44 项行为检查通过；3 种对手分别作为先手／后手，完成 6 局 |
| 浏览器离线性 | 零 HTTP 请求，零页面脚本错误 |
| 单文件许可 | 额外验证根 MIT、来源说明与 119 份 Rust 依赖许可完整嵌入 |
| 本地推理验收 | 13 项测试通过；固定模型哈希一致 |
| 原生／便携搜索一致性 | 196 次搜索请求及最终结果完全一致；四档策略输出一致 |
| 困难／地狱接线 | 分别实际执行 128／256 次搜索模拟 |
| 浏览器与本地服务 | 购买付款、弃还筹码、贵族选择适配；请求取消与来源边界检查通过 |
| Mac 整合运行时 | 使用包内 Python 完成启动检查、四档推理与 12 项页面自测 |
| 发布包 | ZIP CRC、文件 SHA-256、模型身份与许可检查通过 |

页面版权元数据加入后另外完成离线启动检查，模型与游戏逻辑未变化。可复跑的行为测试、验收测试和构建说明见 [开发说明](development.md)。

以上是功能与集成测试，不是人类棋力评级，也不是所有硬件与浏览器的兼容性承诺。Mac 包自带运行环境，未做 Apple 开发者签名或公证。


此包面向 Windows 10/11 的 Intel／AMD x64 电脑。当前实际测试环境是云端 Windows Server 2022／2025，**尚未覆盖 Windows 10/11 实机**；没有进行代码签名。启动说明见 [Windows 本地版](windows.md)。
